## 1. Назначение и концепция проекта

«Лентариум» — концептуальный новостной портал событий и аналитики технологий будущего (2030-е годы).  
Ключевые особенности проекта:
- **Тематические рубрики:** *Экономика*, *Общество*, *Инфраструктура*, *В мире*, *Аналитика*;
- **Главная новость (Hero):** крупный визуальный акцент на ключевом событии дня;
- **Архив по датам и фильтрация:** интерфейс поиска публикаций по календарю и категориям;
- **Избранное:** персональная страница отложенного чтения;
- **Каталог статей (`articles/`):** структурированная директория отдельных страниц материалов с детальным описанием и характеристиками.

Все материалы, персоны и события в проекте являются вымышленными.

## 3. Относительные пути (как устроен переход в `articles/`)

Все страницы публикаций вынесены в поддиректорию `articles/`.  
Для корректного подключения ресурсов внутри файлов `articles/*.html` используются относительные пути с выходом на уровень вверх (`../`):
- Стили: `<link rel="stylesheet" href="../css/style.css">`
- Картинки: `<img src="../images/...">`
- Ссылки на страницы: `<a href="../index.html">`, `<a href="../news.html">`, `<a href="../favorites.html">`
- Внутри CSS-файла `css/style.css` пути к шрифтам (`url("../fonts/...")`) отсчитываются от расположения самого CSS-файла, поэтому работают одинаково для всех страниц проекта.

## 4. Оформление и дизайн новостных карточек

Для решения проблемы перекрытия фотографий текстом внедрены 3 варианта верстки карточек:
1. **Стандартная вертикальная карточка (`.news-card`)** — изображение расположено сверху фиксированной высоты с `object-fit: cover`, а заголовок, дата и текст размещены снизу на контрастном фоне. Картинка видна целиком и не закрывается текстом.
2. **Широкая горизонтальная карточка (`.news-card--wide`)** — изображение слева, текстовый блок справа.
3. **Главный баннер (`.article-banner`)** — полноразмерная обложка с мягким темным градиентом только в нижней трети (заголовок читается отлично, а 70% фото полностью открыты).

## 6. Инструкция по запуску

Проект не требует обязательной сборки и может запускаться автономно:

### Способ 1: Прямое открытие в браузере (без сборщиков)
Просто откройте файл `index.html` в любом современном браузере (двойной клик по файлу или через «Открыть с помощью...» Google Chrome / Yandex Browser / Firefox / Safari). Все ссылки на страницы, шрифты и стили являются относительными и работают автономно.

### Способ 2: Через локальный веб-сервер (VS Code Live Server / Python)
- **VS Code:** установить расширение *Live Server* и нажать кнопку **«Go Live»** внизу редактора.
- **Python:** в папке проекта выполнить команду:
  ```bash
  python -m http.server 3000
  ```
  После чего открыть в браузере: `http://localhost:3000`.
